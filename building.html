Building from source

Arctic builds itself from source, every package included. The whole pipeline runs sandboxed under bubblewrap — the host filesystem is mounted read-only, only the build tree and /tmp are writable. That's not a formality: a recipe that forgets DESTDIR once installed glibc straight over a host's real /usr/lib. It now just fails with EROFS instead of taking the machine down.

Get the pieces

git clone https://github.com/apiwo/arctic-linux
git clone https://github.com/apiwo/arctic-linux-ports arctic-linux/ports

Build

cd arctic-linux
build/arctic-sandbox --check   # prove the sandbox actually holds
build/build.sh                  # the whole pipeline

Or just one step:

build/build.sh iso

Building one package

build/arctic-sandbox build/build-batch.sh <pkg>

Recipes are generated from ports/manifest.tsv — edit the manifest, not the recipe file, unless the package needs something the generic template can't express, in which case drop a recipe.local marker beside it so the generator leaves your hand fix alone.
