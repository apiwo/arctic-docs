Packages (alpm)

alpm is Arctic's own package manager. Binary packages are .alpmz — a tar.xz with a .PKGINFO, .FILES, an optional install script, and the payload rooted at /.

The basics

alpm ins <pkg>              # install a binary package
alpm ins -s <pkg>           # build and install from source
alpm del <pkg>              # remove
alpm del+deps <pkg>         # remove, and now-orphaned dependencies too
alpm search <term>          # search name + description
alpm info <pkg>             # details
alpm list                   # everything installed
alpm update                 # upgrade everything

Flags like -y/--yes work before or after the subcommand — alpm -y ins vim and alpm ins vim -y both work.

Undo

alpm rollback           # undo the last transaction
alpm verify <pkg>       # check installed files against their recorded hashes
alpm doctor              # check the whole system for problems
alpm why <pkg>           # what pulled this in
alpm owns <path>         # which package owns this file

No binary yet?

Not every one of the 500+ packages in arctic-linux-ports has a prebuilt binary on the mirror yet. alpm ins <pkg> offers to compile it from source automatically when there's no binary — same result, just slower the first time.
