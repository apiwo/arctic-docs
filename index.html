What ScrapLinux is

A Linux distribution built from source: a BSD userland over glibc, its own kernel fork, and its own package manager (scrapkg). There is no guided installer - you partition, format and chroot by hand. Once installed, the machine is described in six small files under /etc/scraplinux/, and scraplinux-rebuild makes the machine match them.

Start here

Install covers getting it onto a machine by hand. Configuration covers the six declarative files, and is worth reading properly - it's what makes ongoing maintenance different from an ordinary source distribution.
