Desktops and audio

Desktops

A_DESKTOP=xfce
noneconsole only — the default, and what a bare install still gives you
xfceXFCE 4.22 with LightDM
kdeKDE Plasma 6 with SDDM
niriNiri, a scrollable-tiling Wayland compositor
dwmdwm, suckless and intentionally tiny

Each option is a single profile meta-package that pulls in the whole working environment at once — session, applications, display manager, fonts and audio — rather than leaving you to assemble the pieces and keep them in sync by hand. Choosing a desktop is one line in the config, not a shopping list.

arctic-xfceXFCE, foot, Thunar, notifyd, screenshooter, LightDM, X11, PipeWire, fonts, the Arctic theme
arctic-kdePlasma, foot, Dolphin, Kate, Ark, Spectacle, Gwenview, Okular, SDDM with the Arctic theme, PipeWire, fonts
niri-dmsNiri, DankMaterialShell, foot, fuzzel, mako, swaylock, grim, slurp, XWayland, PipeWire, fonts, Firefox
apiwow-dwmdwm, dmenu, st, picom, slstatus, slock, X11, fonts

Display managers

A_DM=lightdm     # or sddm, greetd, none

Left unset, the chosen desktop's own default is used — LightDM for XFCE, SDDM for KDE. Setting it explicitly overrides that, which is how you get, say, greetd with XFCE instead of LightDM. none means logging in on a text console and starting the session by hand, which is the normal path for a tiling window manager you intend to launch from .xinitrc yourself rather than through a graphical login screen.

Audio

A_AUDIO=y

Installs arctic-sound: PipeWire and WirePlumber as the actual audio and session management layer, the PipeWire PulseAudio compatibility shim so anything expecting a real PulseAudio server still works unmodified, ALSA itself, and alsamixer for the times you need to adjust levels or routing directly rather than through a desktop's own mixer applet. The service is enabled at boot as part of turning this on.

It is also just an ordinary package, which is the same thing stated differently:

SYS_PACKAGES="
	arctic-sound
"

Every desktop profile above already includes the full audio stack on its own, so A_AUDIO mainly matters for a console-only system, or one running a window manager you assembled by hand rather than through a profile.

Bluetooth

A_BLUETOOTH=y

Installs bluez and the PipeWire Bluetooth backend, with bluetoothd enabled. Needs dbus, which is on by default on every install regardless of this setting.

Graphics

A_GPU=auto     # or nvidia, nouveau, amd, intel, generic

auto reads the PCI bus directly and installs whatever driver actually matches the hardware present, rather than installing every driver defensively or guessing from a hardware database.

Fonts

A_FONTS="jetbrains-mono nerd-fonts-symbols noto noto-emoji"

JetBrains Mono and the Nerd Font symbol set are already on the live ISO itself, not only available as an install-time option, so icons in a terminal render correctly from the installer onward rather than only after the first boot of the installed system. The live console gets Arctic's own colour palette applied at boot regardless of which fonts end up installed — that palette change is unconditional and unrelated to this setting.
