install.conf reference

Every setting install.conf accepts, grouped the same way the shipped file groups them, each with its exact default value in its own column. A blank Default means unset — nothing happens unless the line is uncommented. The shipped file documents each of these inline with more context; this is the flat table for when the name and default are all that's needed.

Every line in the shipped file starts as a comment (a #-prefixed line showing the default, exactly as this table shows it) — that's documentation, not a setting in effect. To change something, delete the leading # and give it a real value; a line uncommented with nothing after the = is not the same as leaving it commented out — it's an explicit empty value, and for a yes/no-style option that fails validation the same as a typo would. There's no third state: a line is either a comment (ignored, default applies) or read exactly as written, never both.
