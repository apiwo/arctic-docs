Install

The whole thing, one command

Boot the ISO. Get online if you need to (wired is automatic):

iwctl station wlan0 connect YOUR-NETWORK

Edit the config, then run arctic-strap:

vi /etc/arctic/install.conf
arctic-strap

Everything in install.conf ships commented out, with the default arctic-strap uses right next to it. Uncomment what you want different. The one setting that changes what "run the install" means is A_DISK:

  • Left commented out — manual path. Partition and mount a target yourself first (cfdisk, mkfs.ext4, mkfs.vfat are all on the image), then arctic-strap /mnt.
  • Set to a disk (A_DISK=/dev/sda) — arctic-strap partitions that whole disk, formats it, mounts it, installs the base system, and installs the bootloader. Whatever was on the disk is gone once you run it.

Common settings

A_DESKTOP=niri
A_USER=you
A_USERPASS=change-me
A_ENCRYPT=yes
A_ENCRYPT_PASS=change-me
A_EXTRA=git tmux ripgrep

Full list of every setting, with what it defaults to, is in the config file's own comments — that file is the reference, this page isn't trying to duplicate it.

Bootloader on its own

If you used the manual path, install the bootloader separately. The path tells arctic-boot-strap EFI vs BIOS by itself — /mnt/boot/efi means UEFI, anything else means BIOS:

mount /dev/nvme0n1p2 /mnt/boot/efi
arctic-boot-strap /mnt/boot/efi
