arctic-shell

An ephemeral, reproducible package environment — the same idea as nix-shell/guix shell, built on alpm.

Usage

arctic-shell <pkgs>...                  # drop into an interactive shell
arctic-shell <pkgs>... -- <cmd>...      # run it, tear the environment down after
arctic-shell <pkgs>... -  <cmd>...      # run it, stay in the shell after
arctic-shell --keep <pkgs>...           # leave the environment on disk for next time
arctic-shell --network <pkgs>...        # give it a real network connection
arctic-shell clang -- clang file.c
arctic-shell --keep rust cargo

How it works

Builds a scratch root with exactly the named packages installed (plus the minimal glibc/busybox/toybox base every root needs to have a working shell at all), then chroots into it with your current directory available at the same path, so local files are right there. Without --network the environment has no network access at all — a separate network namespace, not just a missing route.

Environments are content-addressed: asking for the same package set again reuses whatever was already built for it, at /var/cache/arctic-shell/<hash>.
